# CSE P 590B: Cloud Applications (Winter 2025)

This repository contains my projects and assignments for **CSE P 590 Special Topics: Cloud Applications** at the University of Washington.

The course covers principles and patterns of software engineering in the cloud, with hands-on experience using cloud technologies. Topics include distributed architectures, elasticity, security, reliability, availability, and networking.

## Projects

### [Project 1: From Monolith to Cloud-Native](./project1)
*Focus: Analyze a legacy monolithic application, evaluate it against cloud-native and Well-Architected principles, and propose a refactored cloud architecture with before/after diagrams.*

### [Project 2: Cloud Application Post-Mortem Analysis](./project2)
*Focus: Write a blameless production incident post-mortem for a distributed inventory service, including timeline reconstruction, root cause analysis, mitigations, and resilience improvements.*

### [Project 3: Event-Driven Order Processing System](./project3)
*Focus: Design and validate a cloud-native order processing system using asynchronous workflows, queue-based load leveling, infrastructure as code, load testing, and cost analysis.*
